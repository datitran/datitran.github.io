# Personal Homepage

Built with React 18 and Vite.

## Getting Started

```
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view it in the browser.

## Build & Deploy

```
npm run build
npm run preview   # preview production build locally
npm run deploy    # deploy to GitHub Pages
```
